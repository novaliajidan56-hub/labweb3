# Lab3Web
Repositori ini dibuat untuk memenuhi tugas Praktikum 3: CSS Dasar pada mata kuliah Pemrograman Web.

## Isi Folder
1. `lab2_css_dasar.html` - File HTML utama yang menerapkan Internal CSS, Inline CSS, dan Eksternal CSS.
2. `style_eksternal.css` - File CSS Eksternal yang mengatur navigasi, ID Selector, dan Class Selector.
